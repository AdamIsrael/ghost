# M7 Themes (expanded) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Themes become sets of color roles loaded from TOML (14 embedded built-ins plus user files in `<config dir>/themes/`), and the TUI colors statuses, headings, the active tab, selection, diffs, cost and warnings from those roles, with every built-in passing a contrast test.

**Architecture:** New `internal/theme` package: `Palette` (roles), `Load` (built-ins + user dir → `Registry`), color validation, WCAG `Contrast`, `ReadabilityProblems`. `config` validates `theme` against the registry. The TUI replaces its package-level mutable styles with a `styles` value built from the active palette; render helpers become methods on it. `cmd/ghost` loads the registry once and `--check` warns about unreadable user themes.

**Tech Stack:** Go 1.27, `github.com/BurntSushi/toml`, `charm.land/lipgloss/v2` (hex colors are downsampled automatically on 256/16-color terminals), `charm.land/bubbletea/v2` (`View.BackgroundColor`/`ForegroundColor`).

**Spec:** `docs/superpowers/specs/2026-10-10-themes-design.md` (readability rule amended in Task 1).

**Bead:** `ghost-qz7.14` (reopened scope; branch `m7-themes`, which already has the first-pass themes)

## Global Constraints

- Module path `github.com/AdamIsrael/ghost`.
- Roles (TOML keys): `name, background, foreground, muted, border, accent, on_accent, heading, selection, success, warning, error, attention, special, info`. Empty = terminal's own color.
- Colors: `#rrggbb` or ANSI index `0`–`255`. Anything else is an error naming the file and role.
- Built-in ids and cycle order: `dark, light, high-contrast, mono, tokyo-night, tokyo-night-storm, tokyo-night-day, catppuccin-mocha, catppuccin-latte, dracula, nord, gruvbox-dark, solarized-dark, solarized-light`; user themes follow, sorted by id; a user file with a built-in id replaces it in place.
- User themes: `<config dir>/themes/<id>.toml`. Any invalid theme file is a startup error naming the file.
- Readability rule (amended): with a `background`, `foreground` and `muted` ≥ 4.5; `accent`, `heading` and status roles ≥ 3.0 (WCAG non-text/UI threshold — they color icons and short labels); `on_accent` ≥ 4.5 against `accent`; `foreground` ≥ 4.5 against `selection`. Built-ins are tested; user themes only get a `--check` warning.
- Status → role: Ready=success · Draft=muted · Waiting on CI=warning · CI failing=error · Changes requested=attention · Approved=special.
- `auto` (neutral until the terminal answers, then `dark`/`light`), `NO_COLOR` → `mono`, `t` cycles all themes, Ghost never writes `config.toml`: unchanged from the first pass.
- No package-level mutable styles in `internal/tui`.
- **Git:** one commit per task on branch `m7-themes`; ask before merging or pushing.

```go
// Package theme loads TUI color themes: embedded built-ins plus user theme
// files. A theme is a set of color roles; the TUI decides what each role
// colors.
package theme

import (
	"embed"
	"fmt"
	"math"
	"os"
	"path/filepath"
	"regexp"
	"sort"
	"strconv"
	"strings"

	"github.com/BurntSushi/toml"
)

// Palette is one theme. Every role is optional: empty means the terminal's
// own color (or plain/bold/reverse for structure).
type Palette struct {
	ID     string `toml:"-"`
	Source string `toml:"-"` // "built-in" or the file it was loaded from

	Name       string `toml:"name"`
	Background string `toml:"background"`
	Foreground string `toml:"foreground"`
	Muted      string `toml:"muted"`
	Border     string `toml:"border"`
	Accent     string `toml:"accent"`
	OnAccent   string `toml:"on_accent"`
	Heading    string `toml:"heading"`
	Selection  string `toml:"selection"`
	Success    string `toml:"success"`
	Warning    string `toml:"warning"`
	Error      string `toml:"error"`
	Attention  string `toml:"attention"`
	Special    string `toml:"special"`
	Info       string `toml:"info"`
}

type role struct{ name, color string }

func (p Palette) roles() []role {
	return []role{
		{"background", p.Background}, {"foreground", p.Foreground}, {"muted", p.Muted},
		{"border", p.Border}, {"accent", p.Accent}, {"on_accent", p.OnAccent},
		{"heading", p.Heading}, {"selection", p.Selection}, {"success", p.Success},
		{"warning", p.Warning}, {"error", p.Error}, {"attention", p.Attention},
		{"special", p.Special}, {"info", p.Info},
	}
}

//go:embed builtin/*.toml
var builtinFS embed.FS

// BuiltinOrder is the order built-ins are listed and cycled in.
var BuiltinOrder = []string{
	"dark", "light", "high-contrast", "mono",
	"tokyo-night", "tokyo-night-storm", "tokyo-night-day",
	"catppuccin-mocha", "catppuccin-latte", "dracula", "nord", "gruvbox-dark",
	"solarized-dark", "solarized-light",
}

// Registry holds the available themes in display order.
type Registry struct {
	byID  map[string]Palette
	order []string
}

func (r *Registry) Get(id string) (Palette, bool) {
	p, ok := r.byID[id]
	return p, ok
}

func (r *Registry) IDs() []string { return append([]string(nil), r.order...) }

// Load returns the built-ins plus every *.toml file in userDir (which may be
// empty or missing). A user file named like a built-in replaces it in place;
// other user themes follow the built-ins, sorted by id. Any invalid file is
// an error naming it.
func Load(userDir string) (*Registry, error) {
	r := &Registry{byID: map[string]Palette{}}
	for _, id := range BuiltinOrder {
		data, err := builtinFS.ReadFile("builtin/" + id + ".toml")
		if err != nil {
			return nil, err
		}
		p, err := parse(id, "built-in", data)
		if err != nil {
			return nil, err
		}
		r.byID[id] = p
		r.order = append(r.order, id)
	}
	if userDir == "" {
		return r, nil
	}
	paths, err := filepath.Glob(filepath.Join(userDir, "*.toml"))
	if err != nil {
		return nil, err
	}
	sort.Strings(paths)
	for _, path := range paths {
		data, err := os.ReadFile(path)
		if err != nil {
			return nil, err
		}
		id := strings.TrimSuffix(filepath.Base(path), ".toml")
		p, err := parse(id, path, data)
		if err != nil {
			return nil, err
		}
		if _, exists := r.byID[id]; !exists {
			r.order = append(r.order, id)
		}
		r.byID[id] = p
	}
	return r, nil
}

func parse(id, source string, data []byte) (Palette, error) {
	var p Palette
	md, err := toml.Decode(string(data), &p)
	if err != nil {
		return Palette{}, fmt.Errorf("theme %s: %w", source, err)
	}
	if und := md.Undecoded(); len(und) > 0 {
		keys := make([]string, len(und))
		for i, k := range und {
			keys[i] = k.String()
		}
		return Palette{}, fmt.Errorf("theme %s: unknown keys: %s", source, strings.Join(keys, ", "))
	}
	for _, r := range p.roles() {
		if err := checkColor(r.color); err != nil {
			return Palette{}, fmt.Errorf("theme %s: %s: %w", source, r.name, err)
		}
	}
	p.ID, p.Source = id, source
	if p.Name == "" {
		p.Name = id
	}
	return p, nil
}

var hexColor = regexp.MustCompile(`^#[0-9a-fA-F]{6}$`)

func checkColor(c string) error {
	if c == "" || hexColor.MatchString(c) {
		return nil
	}
	if n, err := strconv.Atoi(c); err == nil && n >= 0 && n <= 255 {
		return nil
	}
	return fmt.Errorf("%q is not a #rrggbb color or an ANSI index 0-255", c)
}

func luminance(hex string) float64 {
	channel := func(s string) float64 {
		v, _ := strconv.ParseUint(s, 16, 8)
		c := float64(v) / 255
		if c <= 0.03928 {
			return c / 12.92
		}
		return math.Pow((c+0.055)/1.055, 2.4)
	}
	return 0.2126*channel(hex[1:3]) + 0.7152*channel(hex[3:5]) + 0.0722*channel(hex[5:7])
}

// Contrast returns the WCAG contrast ratio of two #rrggbb colors. ok is false
// unless both are hex (ANSI colors depend on the terminal's palette).
func Contrast(a, b string) (float64, bool) {
	if !hexColor.MatchString(a) || !hexColor.MatchString(b) {
		return 0, false
	}
	la, lb := luminance(a), luminance(b)
	if la < lb {
		la, lb = lb, la
	}
	return (la + 0.05) / (lb + 0.05), true
}

// ReadabilityProblems applies the readability rule. Themes without a
// background use the terminal's, so they can't be checked.
func (p Palette) ReadabilityProblems() []string {
	if p.Background == "" {
		return nil
	}
	var out []string
	check := func(name, fg, bg string, min float64) {
		if c, ok := Contrast(fg, bg); ok && c < min {
			out = append(out, fmt.Sprintf("%s contrast %.2f is below %.1f", name, c, min))
		}
	}
```

```go
package tui

import (
	"image/color"

	"charm.land/lipgloss/v2"

	"github.com/AdamIsrael/ghost/internal/status"
	"github.com/AdamIsrael/ghost/internal/theme"
)

// styles is everything the TUI draws with, built from the active theme.
type styles struct {
	muted, border, heading, activeTab, selected lipgloss.Style
	err, warning, success, attention, special, info lipgloss.Style

	selectionBg            color.Color // nil: selected row uses reverse video
	background, foreground color.Color // whole-screen colors; nil keeps the terminal's
}

func pick(colors ...string) string {
	for _, c := range colors {
		if c != "" {
			return c
		}
	}
	return ""
}

func newStyles(p theme.Palette) styles {
	base := lipgloss.NewStyle()
	fg := func(c string) lipgloss.Style {
		if c == "" {
			return base
		}
		return base.Foreground(lipgloss.Color(c))
	}
	s := styles{
		muted:     fg(p.Muted),
		border:    fg(pick(p.Border, p.Muted)),
		heading:   fg(pick(p.Heading, p.Accent)).Bold(true),
		err:       fg(p.Error),
		warning:   fg(p.Warning),
		success:   fg(p.Success),
		attention: fg(p.Attention),
		special:   fg(p.Special),
		info:      fg(p.Info),
	}
	if p.Accent != "" {
		s.activeTab = base.Bold(true).Background(lipgloss.Color(p.Accent))
		if p.OnAccent != "" {
			s.activeTab = s.activeTab.Foreground(lipgloss.Color(p.OnAccent))
		}
	} else {
		s.activeTab = base.Bold(true).Reverse(true)
	}
	if p.Selection != "" {
		s.selectionBg = lipgloss.Color(p.Selection)
		s.selected = base.Background(s.selectionBg)
	} else {
		s.selected = base.Reverse(true)
	}
	if p.Background != "" {
		s.background = lipgloss.Color(p.Background)
	}
	if p.Foreground != "" {
		s.foreground = lipgloss.Color(p.Foreground)
	}
	return s
}

// status returns the style for a PR status (see the spec's status → role).
func (s styles) status(st status.Status) lipgloss.Style {
	switch st {
	case status.Ready:
		return s.success
	case status.Draft:
		return s.muted
	case status.WaitingOnCI:
		return s.warning
	case status.CIFailing:
		return s.err
	case status.ChangesRequested:
		return s.attention
	case status.Approved:
		return s.special
	}
	return lipgloss.NewStyle()
}

// onSelection gives st the selected-row look, so colored segments of a
// selected row share one highlight.
func (s styles) onSelection(st lipgloss.Style) lipgloss.Style {
	if s.selectionBg != nil {
		return st.Background(s.selectionBg)
	}
	return st.Reverse(true)
}
```
